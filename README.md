# Simple Interest Calculator

This project is a simple interest calculator that calculates simple interest using the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Rate of interest
- Time period

## Example

If:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Output

The calculator displays the calculated simple interest based on the given inputs.
